# Minnette Johnson — MSSE portfolio upload guide

This bundle keeps `index.md` as the homepage required by the assignment. It also improves the Golden Bike Shop architecture decision-record page with a clearer title, decision summary, visual architecture sketch, at-a-glance navigation, a side-by-side options comparison, and clearer separation of rationale, costs, and review triggers.

## Upload or replace these files in your repository

- `_config.yml`
- `index.md`
- `_layouts/default.html`
- `_layouts/decision-record.html`
- `assets/css/style.css`
- `favicon.svg`
- `msse601/MSSE601-ADR-hybrid-architecture.md`

Keep your portrait named `minnette.jpg` in the repository root and keep other course files already in the repository.

## Important

- Do not delete `index.md`; the assignment requires it.
- If an old root-level `index.html` remains from the earlier attempt, remove it after confirming `index.md` is present.
- Keep the exact folder paths above. Create folders in GitHub as needed using **Add file → Create new file**, or upload the extracted folder contents while preserving their paths.
- Commit the changes, then refresh the published site. A browser hard refresh (Ctrl + F5) can help if cached styling remains.
